# Vibescreener

Крипто-скринер: фьючерсы и спот Binance, Bybit, OKX, Bitget и Hyperliquid.

- **Скринер** — сетка свечных графиков. Монеты ранжируются по росту / падению / движению **цены или открытого интереса (ОИ)**
  за 5м, 15м, 1ч, 4ч или 24ч. Фильтры: рынок (фьючерсы / спот), биржи, минимальный объём, поиск; таймфрейм графиков 1m…1d;
  сетка 2×2 … 4×4; «Без дублей» оставляет каждую монету один раз — с биржи с наибольшим оборотом.
- **Обзор рынка** — справа список всех монет выбранной биржи (ширина меняется перетаскиванием края; ⇄ — перенести влево),
  слева три графика выбранной монеты, у каждого свой таймфрейм: большой на всю высоту и два малых друг над другом.
  Сортировка списка: название, цена, 24ч %, объём, NATR; если растянуть список шире — появляются 5м/15м/1ч/4ч и ОИ.
  Под большим графиком — график открытого интереса (монеты / $). Стрелки ↑↓ переключают монету.
- **Открытый интерес** — только у фьючерсов. Изменение считается в монетах (так цена не искажает сигнал). Источники:
  Bybit, Bitget, Hyperliquid, OKX отдают ОИ в тикерах, у Binance он берётся из истории 5м. Для старта подтягивается история
  бирж (Binance и Bybit ~25ч, OKX ~48ч по часам), дальше ОИ копится сам и сохраняется в `data/oi.bin`. У Bitget и Hyperliquid
  истории нет — окна 1ч/4ч/24ч заполнятся по мере работы программы.
- **Инструменты на графиках** — двойной ЛКМ: алерт на цену; ПКМ по линии 🔔: удалить алерт; ПКМ по плитке скринера: большой график;
  **Shift + средняя кнопка мыши (зажать и вести)** — линейка: изменение в %, разница цены, число свечей и время.
- **Алерты** — два вида. Работают на сервере, поэтому срабатывают и при закрытой вкладке.
  - *Разовые по цене* — пересечение уровня; направление определяется по текущей цене. Самый быстрый способ —
    **двойной клик ЛКМ по графику** (в плитке скринера или в большом графике): алерт ставится в точку клика,
    на графике появляется линия 🔔, в тосте есть кнопка «Отменить». Сработав, алерт выключается.
  - *Повторяющиеся (комплексные)* — несколько условий сразу (И) по разным метрикам (изменение цены и ОИ за 5м…24ч, NATR,
    объём, ОИ в $, цена), список монет или `*`, выбор бирж, пауза на монету. Срабатывают при пересечении и затем снова.
  - Уведомления: всплывашка + звук + системное уведомление браузера (кнопка 🔔 в шапке) + **Telegram в личку**.

## Запуск

```bash
./run.sh          # http://localhost:8000
./run.sh 9000     # другой порт
```

Нужен Python 3.11+. Зависимости: fastapi, uvicorn, httpx. Фронтенд — обычный JS без сборки.

### Telegram-уведомления

Настраиваются в интерфейсе (Алерты → карточка Telegram): создай бота у @BotFather, вставь токен, нажми Start у бота и
«Найти мой chat id». Токен и chat id сохраняются в `data/settings.json` (права 0600). Либо задай через окружение:
`TELEGRAM_BOT_TOKEN=… TELEGRAM_CHAT_ID=… ./run.sh`.

Алерты и история лежат в `data/alerts.json` (путь можно сменить через `SCREENER_DATA_DIR`).

> По умолчанию сервер слушает только `127.0.0.1`: у API нет авторизации, а в нём хранится токен бота.
> `HOST=0.0.0.0 ./run.sh` открывает доступ из сети — делай это только в доверенной сети или за reverse-proxy с паролем.

## Как это устроено

- `app/exchanges/` — по модулю на биржу: тикеры за 24ч (один запрос на рынок) и свечи.
- `app/collector.py` — опрашивает тикеры каждые 5с (Hyperliquid — 10с) и в фоне обходит монеты с оборотом ≥ $300K,
  подгружая 300 минутных свечей (с учётом лимитов каждой биржи).
- `app/store.py` — из минуток считает изменение за 5м/15м/1ч/4ч относительно живой цены и **NATR 5/14**
  (ATR по Уайлдеру на 5-минутных свечах, период 14, в % от цены).
- `app/alerts.py` — движок алертов: срабатывает при **пересечении** порога, пауза на монету, режим «один раз».

Сразу после старта 5м/15м/1ч/4ч и NATR есть не у всех монет: свечи подгружаются по очереди, начиная с самых ликвидных
(Binance/Bybit/OKX — около минуты, Hyperliquid — заметно дольше из-за строгого лимита API). Монеты без данных за выбранный
период в скринере пропускаются, а в обзоре рынка показывают «—». 24ч-показатели есть сразу.

Графики: [TradingView Lightweight Charts™](https://www.tradingview.com/lightweight-charts/) (лежит в `app/static/vendor/`).

## Windows и обновления

Готовый exe собирает GitHub Actions (`.github/workflows/release.yml`): при пуше тега `v*` собирается
`Vibescreener-win64-vX.Y.Z.zip` и выкладывается в Releases. Новая версия:

```bash
git tag v1.1.0 && git push --tags
```

Пользователь скачивает zip, распаковывает **поверх старой папки** — алерты и настройки (папка `data`) сохраняются.
Если репозиторий публичный, программа сама проверяет новые релизы и показывает в шапке плашку «Доступна vX.Y.Z».
Локальная проверка сборки: `pip install -r requirements-build.txt && pyinstaller --noconfirm vibescreener.spec`.
