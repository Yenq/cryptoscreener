Vibescreener — крипто-скринер (Windows)

ЗАПУСК
  Запусти Vibescreener.exe. Откроется окно с логами и страница в браузере (http://127.0.0.1:8000).
  Чтобы остановить — закрой окно с логами.
  Если Windows SmartScreen пишет «Неизвестный издатель» — «Подробнее» → «Выполнить в любом случае»
  (программа не подписана сертификатом).

ОБНОВЛЕНИЕ
  Скачай новый архив, распакуй ПОВЕРХ старой папки (с заменой файлов).
  Твои алерты и настройки Telegram лежат в папке data\ — она при этом не затрагивается.
  Если в шапке программы появилась жёлтая плашка «Доступна vX.Y.Z» — это ссылка на новую версию.

TELEGRAM
  Алерты → карточка Telegram: токен бота от @BotFather, нажми Start у бота, «Найти мой chat id», «Тест».

УПРАВЛЕНИЕ В СКРИНЕРЕ
  ПКМ по плитке — большой график. Двойной клик ЛКМ по графику — разовый алерт на цену в этой точке.
  ПКМ по жёлтой линии 🔔 — удалить алерт.
